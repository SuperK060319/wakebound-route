# 《潮痕航路》健康知识审核报告

审核日期：2026-08-22  
审核范围：`health-content.js`、健康家书及现有四章航海故事；仅审查内容与素材，不评价诊疗方案。

## 结论

**有条件通过。** 四条核心健康知识均可由国家卫生健康委《中国公民健康素养——基本知识与技能（2024年版）》直接支持，来源链接、发布机构和“不能替代诊断或治疗”的声明均合格；全文没有对玩家作诊断，也没有要求停药、替代就医或承诺治愈。

上线前建议优先处理两项：

1. 把所有健康主题奖励明确标为“叙事性游戏机制”，避免玩家把健康行为理解成即时、确定的身体收益。
2. 不把饮食对应“药剂”、无烟对应“最大生命/立即修复”；这两组映射最容易形成“食物等于药物”“戒烟立刻恢复生命值”的错误因果。

## 风险与修改建议

### 高优先级：奖励造成错误健康因果

- `睡眠 → 修复12点船体` 尚可解释为轮值改善后的航船管理结果，但仍需标明是游戏机制。
- `运动 → 强化卡牌` 是训练改善战术熟练度的叙事隐喻，风险较低。
- `膳食 → 随机药剂` 容易暗示日常饮食能替代药物，建议改成金币、补给券或普通卡牌奖励。
- `无烟 → 最大生命+4并立即修复` 容易暗示戒烟会即时、确定地恢复身体，建议改成无健康含义的船体硬件、金币或航线资源。

统一提示建议放在首次健康选择及家书来源区：

> 健康行动依据公共健康资料改写；奖励仅为航海叙事与游戏机制，不代表现实中的即时效果或结果保证。

### 中优先级：尊重不同健康状况与生活处境

- 运动文案已有“健康成年人”“量力而行、循序渐进”，包容性较好；建议再覆盖慢性病、残障、孕产期、康复期等需个体化安排的人群。
- “今晚提前放下手机”不适用于轮班工作者、照护者或受失眠等问题困扰的人，宜改为不带责备的可选行动。
- “多选一种蔬菜”总体安全，但应避免把健康完全归因于个人意志；过敏、疾病饮食要求、经济和食物可及性均可能限制选择。
- 戒烟内容使用“陪伴、求助”而非羞辱，处理得当；不要设置惩罚吸烟者或把复吸写成道德失败。

### 低优先级：叙事措辞

家书中的“船医日志”可能让一般科普看起来像个体医疗建议，建议改为“航海健康手册”。节日祝福整体克制，没有“健康即义务”“患病等于不自律”等歧视性表达。

## 可直接替换的安全文案

以下文案保持原主题，不改变 `id`。

### 通用声明

```text
内容用于一般健康知识普及，不能替代专业医务人员的个体化诊断或治疗建议。每个人的年龄、身体状况和生活条件不同；如有不适、已有疾病或对行动是否适合自己有疑问，请咨询专业医务人员。游戏奖励仅为航海叙事机制，不代表现实中的即时健康效果或结果保证。
```

### 睡眠

```text
知识：劳逸结合、起居有常，并尽量保证适合自己的充足睡眠。
船上行动：重新安排轮值，减少不必要的连续通宵；让船员在职责允许时获得稳定休息。
家庭行动：今晚一起找一个不增加负担的小调整，例如稍早结束一件非必要的事；轮班、照护或睡眠困难时，不必勉强用同一种作息标准要求自己。
结果：新的值夜表贴上桅杆。海仍然很黑，但休息不再被当成软弱，也不再要求谁独自硬撑。
```

### 运动

```text
知识：健康成年人每周应进行150～300分钟中等强度或75～150分钟高强度有氧运动，每周应进行2～3次抗阻训练。
船上行动：按每个人的能力安排短时活动，量力而行、循序渐进；已有疾病、残障、孕产期或康复期人员按专业建议调整方式和强度。
家庭行动：从大家愿意且适合的活动开始；步行、轮椅活动、拉伸或其他可持续方式都可以，不以速度和完成量互相比较。
结果：训练不再是临战前的惩罚，而成为可以调整、可以暂停、也可以长期坚持的日常安排。
```

### 膳食

```text
知识：膳食要清淡，少盐、少油、少糖，并注意食物多样和合理搭配。
船上行动：在条件允许时减少高盐腌渍补给，采购时查看食品标签，并增加可保存的多样食物；有过敏或特殊饮食要求者单独记录。
家庭行动：下次买菜时，在预算、可获得食物和个人饮食要求允许的范围内，尝试增加一种合适的食物，也可以一起看看预包装食品标签。
结果：厨舱没有变成诊室，只是采购单更清楚，也给不同需要的人留出了选择。
```

建议把奖励替换为：

```text
航程奖励（游戏机制）：获得35枚金币
```

### 无烟

```text
知识：不吸烟（含电子烟）；吸烟和二手烟暴露会导致多种疾病。任何年龄戒烟均可获益，需要时可寻求专业戒烟服务。
船上行动：生活舱和火药舱设为无烟空间；需要戒烟帮助的船员可自愿获得港口专业服务信息，不因依赖或复吸受到羞辱。
家庭行动：把家里和车里约定为无烟空间；如果对方愿意戒烟，陪他寻找专业支持，不指责，也不把一次复吸当成失败定论。
结果：无烟标记贴到住舱。有人主动提出返航后了解专业戒烟服务，其他人只负责支持，不替他作诊断。
```

建议把奖励替换为：

```text
航程奖励（游戏机制）：获得1件随机船体硬件
```

### 家书固定句

将：

```text

```

替换为：

```text
这次出海，我在航海健康手册里记住一件事：
```

```text

```


## 发布前最小检查清单

- 每条具体数字仍有可点击的权威来源和复核日期。
- 不出现“保证、治愈、立刻恢复、人人都应做到”等结果承诺。
- 个体化健康问题只引导咨询专业人员，不在游戏中判断病因或给治疗方案。
- 健康主题奖励统一带“游戏机制”标签，且优先使用金币、硬件、航线资源等中性奖励。
- 不因疾病、残障、体重、睡眠困难、烟草依赖或复吸羞辱、惩罚玩家。
