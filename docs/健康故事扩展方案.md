# 《潮痕航路》健康故事扩展方案

> 版本定位：下一版可实施的健康支线设计稿  
> 范围：只扩展叙事、地图反馈和既有战斗奖励，不改写现有 8 站主线骨架。  
> 核心原则：先让玩家追一个好玩的海上悬案，再让健康知识成为破解悬案和赢下战斗的方法；不出现答题弹窗、知识测验或“正确答案”按钮。

## 1. 现状判断

### 1.1 现有主线骨架

现有航程是固定 8 层、动态分叉的单海域：

| 站位 | 现有节点范围 | 主线节拍 |
|---|---|---|
| 第 1 站 | 普通战 | 序章在进站前触发：从“救人 / 查真相 / 夺航图”中确定誓言，并决定最终首领形态 |
| 第 2 站 | 普通战 + 事件或宝藏 | 暂无强制主线，适合第一处支线伏笔 |
| 第 3 站 | 精英或普通战 | 进站前触发“失踪舰队的第七码”：救弥娅或取黑匣子 |
| 第 4 站 | 船坞 + 事件或普通战 | 暂无强制主线，适合第二处支线伏笔，并可连接船坞整备 |
| 第 5 站 | 精英 + 宝藏 | 进站前触发“父亲留下的第二条航线”：修复批注或拆导航核心 |
| 第 6 站 | 普通战/事件 + 维修港 | 暂无强制主线，适合第三处支线伏笔，并可连接维修港 |
| 第 7 站 | 精英 + 事件 | 进站前触发“最后一盏可以点亮的灯”：点亮信标或暗中接近 |
| 第 8 站 | 最终首领 | 按序章誓言切换守墓者、真相型或夺图者，并按四章选择生成结局 |

现有 `storyChapters` 在 `floor = 0 / 2 / 4 / 6` 触发，承担“进奇数站前的大章节”。健康支线不应再挤进同一时点，否则玩家会连续读两次弹窗。下一版采用“完成偶数站后、返回地图时出现 20～35 秒短场景”的交错节拍：主线负责大秘密，支线负责船上正在发生的小麻烦。

### 1.2 可直接复用的健康资产

`health-content.js` 已经提供四个可引用主题及现成奖励：

- `sleep`：双班轮值；修复 12 点船体。
- `activity`：短时甲板快走与绳结抗阻练习；随机强化 1 张卡。
- `diet`：少盐、少油、少糖、食物多样并查看食品标签；现数据是“随机药剂”，但同目录健康审核报告已建议改为 35 金币等中性航程资源，避免“食物等于药物”的联想。
- `smokeFree`：生活舱与火药舱无烟，需要时寻求专业戒烟帮助；现数据是“最大生命 +4、修复 4”，但健康审核报告已建议改为随机船体硬件等中性资源，避免“戒烟会立即恢复生命”的联想。

下一版只引用 `topicId`，不在故事数据里复制健康事实。知识原文继续由 `health-content.js` 单点维护；故事只呈现人物为何要做、具体做了什么、做完发生了什么。奖励接入前先采用《健康知识审核报告》的中性映射，并统一注明“奖励仅为航海叙事与游戏机制，不代表现实中的即时健康效果或结果保证”。

## 2. 支线总案：《第四更仍在响》

### 一句话卖点

逐潮者号每到午夜都会多响一次不存在的更钟；玩家追查后发现，那不是鬼，而是一名从失踪舰队活下来的更钟官在偷偷制造假警报——他相信只要所有人永远醒着，三年前的灾难就不会重演。

### 玩家先感受到的乐趣

1. 船上出现“多出来的一更”，像海上怪谈。
2. 每个伏笔都有可观察的物证：不可能的值夜记录、被磨掉的补给标签、从火药舱飘出的甜烟。
3. 嫌疑人并非坏人。他的假警报曾经真的救过船，因此玩家会犹豫该不该立刻揭穿。
4. 最终首领会学会这套钟声。前三次调查不是收集文本，而是在为 Boss 战识破一次致命假意图。

## 3. 角色设计

### 3.1 核心角色：更钟官唐栗

- **身份**：失踪舰队第七码的见习更钟官，二十岁上下；玩家在第 3 站附近确认他随漂流舱登船，但第一处伏笔可以先只出现他的字迹和铜哨。
- **外观锚点**：腰间挂四枚铜铃，只有三枚会响；总在数绳结，困得站着也能打盹；说谎时会把第四枚不响的铜铃攥进手心。
- **好玩之处**：一本正经地给所有东西排班——连甲板上的海鸥都有“擅离岗位”记录。嘴硬、执行力极强，偶尔制造荒诞军纪喜剧。
- **欲望**：让逐潮者号平安穿过无灯海，证明自己不是害死哥哥的懦夫。
- **秘密**：三年前无灯塔熄灭时，他在第四更睡着了；醒来后哥哥和整支舰队都失踪。他把相关性误当因果，从此偷偷启动失踪舰队的“长明航令”，用假警报逼所有人保持清醒。
- **弧光**：从“只有我盯住所有人才安全”，走到“可靠的制度、互相交接和求助，比一个人硬撑更能保护同伴”。

### 3.2 既有角色的接法

- **洛弥**：最先指出“逐潮者号的值夜表只有三班，没人被排到第四更”，承担悬疑入口，不承担健康说教。
- **弥娅已获救时**：她认出长明钟来自失踪舰队，但选择先观察唐栗，人物关系偏温柔。
- **玩家取了黑匣子时**：黑匣子播放出唐栗哥哥的最后交接记录，证据更冷、更硬；不依赖弥娅也能完成支线。
- **两者都不是当前场景条件时**：由导航核心或父亲批注提供同等信息。支线不能因主线二选一而断档，只改变台词来源。

## 4. 冲突结构

### 表层冲突

谁在深夜敲响不存在的第四更？他是在救船，还是在把整船人拖垮？

### 中层冲突

唐栗确实靠假警报提前发现过一次敌袭，因此“持续警觉”不是纯粹错误。问题在于他把一次有效的应急手段，变成了不能停下的日常制度。

### 深层冲突

主线追问“失踪者的记忆应该被带回、查明还是夺回”；支线追问“纪念失踪者，是否等于复制他们最痛苦的生存方式”。健康行动因此不是现代知识硬贴海盗世界，而是角色如何摆脱创伤控制的具体办法。

## 5. 三次伏笔与通关回收

### 伏笔一：第 2 站后——《不存在的第四更》

**开场画面**：普通战或事件结束后，全船刚安静，铜铃连续响四次。镜头扫过横七竖八睡在岗位边的船员；航海日志却写着“全员精神良好”。

**物证**：四次值夜记录的字迹完全相同，最后一页沾着唐栗常用的栗色封蜡；此时不点名他。

**短冲突**：洛弥主张找出敲钟者；一名炮手却说第四更昨晚让他提前看见海盗帆影，不能贸然停掉。

**玩家做的不是答题，而是下令**：

- `把一人通宵改成双班轮值`：引用 `sleep`。当场不是弹出知识点，而是出现新的值夜表、交接铜牌和“谁也不必独自撑到天亮”的结果；结算修复 12 点船体。
- `保留第四更，给敲钟者设套`：不判错，获得“假警报诱饵”——下一场战斗首回合看见敌人第二回合意图；但船员疲惫的视觉线索继续累积。该选择让悬疑更强，后续仍可转向改善方案。

**第一处健康信息的自然进入方式**：角色先做双班轮值，事实说明只在“航海故事”展开详情或家书中出现。主场景只写行动和结果。

**伏笔作用**：玩家知道有人伪造值夜记录，却仍不确定动机；“第四更有时真能救人”保留道德张力。

### 伏笔二：第 4 站后——《被磨掉的补给标签》

**开场画面**：船坞或战斗后，厨舱发现一箱失踪舰队补给。每个标签都被磨去，只剩同一行手写字：“越咸越醒，越甜越稳。”旁边的绳架积灰，船员临战拉绳时却频繁打结。

**物证**：补给箱夹层藏着长明航令的半张维护表：它要求用重口补给、甜酒和连续静坐守岗维持“清醒效率”。维护表右下角画着四枚铃，其中一枚被人涂黑。

**人物戏**：唐栗突然出现，以“旧舰队就是靠这个活下来的”为补给辩护。他能准确说出箱内数量，却坚持自己从没开过箱，第一次明显露出破绽。

**玩家做的不是选择健康常识，而是重整一场即将开始的登船战**：

- `重写采购单，按标签把补给分舱`：引用 `diet`。厨舱在条件允许时增加不同种类食物、减少高盐腌渍补给，并为过敏或特殊饮食要求单独标记；包装标签变成后续识别假补给的线索。获得 35 金币的“清点结余”，不生成药剂。
- `把积灰的绳架改成每日短训场`：引用 `activity`。训练表现为装填、拉索、急停和协同登船，不出现“请运动”的台词；随机强化 1 张牌，强化动画可解释为这张战术被练熟。

两项在后续航程都可补齐：本次选择决定即时奖励，未选择的一项可在第 6 站维修港以低成本“补做船务”完成，避免为了收齐健康主题被迫重开。

**伏笔作用**：玩家确认第四更不是超自然现象，而是一套旧舰队制度；但仍不知道谁重启了它，以及涂黑的第四枚铃代表谁。

### 伏笔三：第 6 站后——《火药舱里的甜烟》

**开场画面**：维修港刚熄灯，火药舱通风口飘出带甜味的烟。唐栗被发现坐在长明钟旁，手里不是武器，而是哥哥留下的第四枚哑钟。

**物证回扣**：

1. 第一处同字迹值夜记录，是唐栗替所有人签的。
2. 第二处磨掉标签，是他怕船员看见旧舰队已给这套制度标注“仅限 24 小时紧急状态”。
3. 烟来自他分发的“醒神烟”；它进入生活舱，也靠近火药舱。他不是为了害人，而是在惊恐时复刻哥哥最后一天的做法。

**核心对话**：

> 唐栗：“那晚我只睡了一更。醒来以后，他们全没了。”  
> 洛弥：“所以你让整条船替你守那一更？”  
> 唐栗：“只要钟不停，下一次失踪就追不上我们。”

**玩家下的是船规，不是健康测验**：

- `封存长明钟，生活舱与火药舱全面无烟`：引用 `smokeFree`。同时明确“需要戒烟帮助的船员可自愿了解港口专业服务”，不把戒烟写成靠意志瞬间完成，也不因依赖或复吸羞辱角色。清理火药舱时发现并安装 1 件随机船体硬件；不增加生命或即时修复。
- `让唐栗亲手改造长明钟`：解锁角色和解路线。钟不再制造假警报，而是只在两班共同确认后报警；下一场精英战第一次错误意图会被识破。
- `将唐栗关进底舱`：保留惩戒路线。玩家仍可执行无烟船规，但失去“亲手改钟”的首领战优势；结局变为唐栗在返港审理前第一次主动请求睡一晚。

**伏笔作用**：揭开人物秘密，同时留下最终问题——无灯塔已经听见长明钟的节奏，关掉它还来得及吗？

### 通关回收：第 8 站首领战与结局——《真正的警报》

**战斗前回收**：无论序章选择对应哪一种首领，Boss 第一阶段都截取失踪者声音并敲响四次更钟。界面不弹知识题，而是给出一次战术决策：相信钟声立刻出牌，还是按已建立的交接制度确认敌人意图。

**完成三处调查时的机制回收**：

- 地图上的三枚潮印在首领节点连成一条“交接绳”。
- 唐栗和两班船员完成交叉确认，揭穿一次“伪装攻击”意图。
- 实施 `sleep`：首领第一阶段结束后修复少量船体，表现为轮休班组接手损管。
- 实施 `activity`：一张已强化的战术牌在首回合进入手牌，表现为平日练熟的动作。
- 实施 `diet`：清楚的分舱标签让船员识破一箱被调包的假补给，保住本来已有的一瓶药剂；若没有药剂，则显示为战斗叙事反馈，不凭空治疗。
- 实施 `smokeFree`：通风清楚、火药舱无烟后，瞭望员能看见真实灯号；它与三线索共同帮助识破假意图，不产生即时生命恢复。

上述效果应以已有的修复、强化、金币、硬件、首回合抽牌、保住既有资源或意图识破表达，不新建复杂战斗资源。每项收益小而可感知，避免健康支线成为唯一最优路线，也避免把健康行动包装成即时治疗。

**角色回收**：无灯塔模仿唐栗哥哥的声音说“别睡”。唐栗没有再次敲钟，而是把第四枚哑钟交给下一班，回答：“我下班了，你来守。”这句是人物弧光的完成点，也是整条支线的记忆点。

**通关后场景**：新值夜表、训练绳架、补给标签和无烟标记同时出现在甲板，不进行四条知识复述。玩家选择其中一个“最想写回家”的行动生成家书主题；家书页再显示相应的权威健康事实与一般性免责声明。

## 6. 与地图的连接

### 6.1 触发规则

支线采用“层级必达、节点换皮”而不是“指定节点才有内容”：

- 第 2、4、6 站完成并返回地图时各触发一次。
- 所走节点类型只改变开场包装：战斗后是船损与疲劳，事件后是打捞物证，船坞后是改装发现，维修港后是舱室检查。
- 不能因为随机路线没有事件节点而漏掉伏笔。
- 每次短场景控制在 90～140 字正文、2～3 个行动选项、一次即时反馈；总阅读时间不超过 35 秒。

### 6.2 地图视觉反馈

- 第一处完成：第 2 站节点旁出现一枚小铜铃潮印。
- 第二处完成：第 4 站与第 2 站之间出现一段虚线“栗色封蜡线”。
- 第三处完成：三枚潮印连向 Boss，但线条仍断一格，直到第 7 站主线选择后才闭合。
- 这些标记表达“悬案进度”，不叫“健康任务 1/3”，避免任务清单感。

### 6.3 与主线选择的互文

| 主线旗标 | 支线变化 |
|---|---|
| `vow-home` | 唐栗更害怕“因自己失职让别人回不了家”；通关回收强调交班和返航名单 |
| `vow-truth` | 玩家更早怀疑钟声来自设备；黑匣子/导航核心证据更完整 |
| `vow-reclaim` | 唐栗曾把长明钟当成被海盗抢走的舰队财产；冲突更偏“旧制度是否也值得夺回” |
| `saved-signal` | 弥娅参与拆钟并为唐栗保留体面，不改变机制 |
| `took-blackbox` | 由哥哥的最后录音揭示真相，不依赖弥娅 |
| `restored-notes` | 父亲批注提前写明“第四更仅用于紧急状态” |
| `salvaged-core` | 导航核心能识别 Boss 模仿的假钟声 |
| `lit-beacon` | 首领用公开信标放大假钟声；玩家以全船交接公开反制 |
| `shadow-route` | 假钟声在黑暗里更有压迫感；唐栗用静默手势完成交班 |

支线只追加一到两句条件台词，不改写主线结果，不再制造一套平行结局树。

## 7. 与战斗的连接

### 7.1 设计原则

1. **行动先于解释**：玩家先排班、训练、改补给、定舱规，再从船务和战术反馈理解它们为何有效。
2. **不设健康分数**：不出现“健康值”“文明值”或道德红绿灯。
3. **不设唯一正确路线**：调查、惩戒、和解都能通关；健康行动影响资源和角色回收，不把玩家贴成“错误”。
4. **复用现有机制**：优先使用船体修复、卡牌强化、金币、硬件、首回合抽牌、敌方锈蚀和意图展示；涉及健康主题时避免映射为个体生命值的即时变化。
5. **收益有时限**：即时奖励足够让玩家记住行动，但不能永久碾压普通构筑选择。

### 7.2 推荐的 V1 数值

| 行动 | 现成奖励 | 叙事解释 | 平衡边界 |
|---|---:|---|---|
| 双班轮值 | 修复 12 | 休息过的损管班接手抢修 | 不超过一次普通维修港收益的一半 |
| 甲板短训 | 随机强化 1 张 | 一项战术被反复练熟 | 只强化未强化卡；无目标时换 35 金币 |
| 重写采购单 | 35 金币 | 清点、分舱后发现采购结余 | 中性航程资源；不映射成药物或治疗 |
| 全船无烟 | 随机船体硬件 1 件 | 清理火药舱时找回并安装旧部件 | 中性船务资源；已有硬件满级时换 60 金币 |
| 三伏笔全调查 | 首领识破 1 次假意图 | 证据链让全船不再盲从钟声 | 不直接造成伤害，不替代构筑输出 |

### 7.3 战斗演出建议

- 双班轮值：回合交替时，船侧灯从一排熄灭、另一排点亮；不额外弹文字。
- 甲板短训：被强化卡首次抽到时闪过绳结印记。
- 补给分舱：金币结算旁出现带标签的小木箱和“清点结余”，不新增按钮。
- 无烟舱规：通风口吹散灰雾，瞭望员看清真实灯号；硬件奖励来自舱室清理，不表现为人物立刻恢复。
- 假意图：Boss 头顶意图先短暂显示错误图标，交接绳拉紧后翻为真实意图，让玩家感到前三次调查真的救了这一回合。

## 8. 可扩展的数据与内容结构

此处是后续实现合同，不要求本任务修改代码。

### 8.1 与主线解耦

不要直接继续膨胀 `storyChapters`。建议新增独立数据包，例如 `crewArcs`：

```js
crewArcs.fourthWatch = {
  id: 'fourth-watch',
  title: '第四更仍在响',
  beats: [
    { id: 'bell-4', triggerAfterFloor: 1, topicIds: ['sleep'] },
    { id: 'scraped-labels', triggerAfterFloor: 3, topicIds: ['diet', 'activity'] },
    { id: 'sweet-smoke', triggerAfterFloor: 5, topicIds: ['smokeFree'] }
  ],
  payoff: { trigger: 'victory', requiresSeen: 3 }
};
```

每个 beat 只保存：场景文本、节点类型变体、选择、故事旗标、所引用的 `topicId` 和效果适配器。健康事实、家庭行动和免责声明仍从 `WAKEBOUND_HEALTH.topics[topicId]` 读取。

### 8.2 建议的存档状态

```js
state.crewArcs = {
  'fourth-watch': {
    seen: ['bell-4'],
    flags: ['double-watch'],
    clues: 1,
    resolved: false
  }
};
```

- 不占用 `state.story.seen`，避免影响现有永久主线档案的 `4 / 4` 统计。
- 永久档案只记录看过的支线结局与家书主题，不跨航程继承战斗收益。
- 新增主题时只添加 topic 和 arc beat，不改已有 `id`，保护旧存档。

### 8.3 后续主题的扩展模板

每个新健康主题必须回答五个问题：

1. 船上先发生了什么有趣或危险的事？
2. 哪个角色因为自己的欲望做出了这个选择？
3. 玩家采取的具体船务行动是什么？
4. 现有战斗/地图机制如何反馈，而不是再开一个小游戏？
5. 通关时哪一个人物动作或物件能回收它？

可扩展方向示例：

- 口腔健康：咬不开信号绳封蜡的老炮手，连接药剂使用和维修港。
- 急救素养：被误传成“海妖诅咒”的外伤事故，连接意图判断和战后处理；避免把复杂急救简化为无条件操作。
- 心理健康：听见失踪者声音后的回避与求助，连接无灯塔的记忆攻击；不把正常情绪病理化。
- 传染病防护：港口临时检疫与通风协作，连接路线风险；涉及具体措施时必须重新核验权威来源与适用条件。

## 9. 文案与交互禁区

- 不写“以下哪项是正确做法”。
- 不让角色突然背诵完整指南、分钟数或疾病清单。
- 不把不健康行为者写成坏人、愚蠢的人或需要被嘲笑的人。
- 不用单次健康选择决定生死或给玩家贴道德标签。
- 不把一般健康知识写成诊断、治疗方案或个体医疗建议。
- 不让健康弹窗截断出牌或 Boss 阶段；事实详情放在航海故事、家书或可选资料页。
- 不复制 `health-content.js` 中的事实文案到多个剧情文件，避免更新时相互矛盾。

## 10. 最小实现顺序

### 阶段 A：先验证故事好不好玩

1. 只制作三段短场景和通关台词，不接数值。
2. 用一次完整 8 站试玩验证：玩家能否在第三段前猜到“人为”，但猜不到唐栗的完整动机。
3. 询问试玩者记住了什么。优先目标是“第四更、哑钟、我下班了你来守”，其次才是四个健康主题名称。

### 阶段 B：接既有奖励

1. 将四个 `topicId` 对应到审核后的 heal / upgrade / gold / hardware 效果；其中 heal 明确解释为轮值改善后的船体损管，不是人体即时收益。
2. 为无可强化卡、硬件满级等情况加中性替代收益。
3. 验证支线奖励不超过一条普通高收益路线的总价值。

### 阶段 C：接地图与首领

1. 加三枚潮印和连线，不改变路线可达性。
2. 仅给 Boss 增加一次假意图演出与一次识破结算。
3. 分别验证三种序章首领、`saved-signal` / `took-blackbox` 两条证据来源、`lit-beacon` / `shadow-route` 两种进场方式。

### 阶段 D：接家书与永久档案

1. 通关后从本航程实际完成的主题中选择家书内容。
2. 家书详情读取权威事实与免责声明。
3. 永久档案记录人物结局和已见选择，不继承数值。

## 11. 验收标准

- [ ] 不修改现有 8 层路线结构和四章主线触发点。
- [ ] 随机路线无论出现何种节点组合，都能看到三处伏笔。
- [ ] 三个伏笔各有独立物证，并在第 6 站形成完整证据链。
- [ ] 唐栗的行为同时有可理解动机和真实代价，不是功能性“知识讲解员”。
- [ ] 四个现有健康主题都通过船务行动出现，没有答题弹窗。
- [ ] 饮食不生成药剂，无烟不增加生命或即时修复；所有奖励注明仅为游戏机制。
- [ ] 未阅读健康资料页的玩家也能理解剧情和操作后果。
- [ ] 首领战至少有一次可见的支线机制回收，而非只改结局文字。
- [ ] 三种首领形态及两组主线分支都不会造成支线断档。
- [ ] 所有健康事实只从统一数据源读取，保留来源、复核日期和免责声明。
- [ ] 完成一局后，玩家能复述至少一个物件线索、一个人物动机和一个自己执行过的船务行动。

## 12. 本版最重要的一句

> 唐栗把第四枚哑钟交给下一班：“我下班了，你来守。”

如果玩家最后记住的是这句，而不是“游戏让我做了四道健康题”，这条健康支线就成立了。
